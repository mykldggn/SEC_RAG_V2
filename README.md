SEC RAG Pipeline
================

A Retrieval-Augmented-Generation (RAG) backend for extracting structured information from SEC EDGAR filings using OpenAI.

Prerequisites
-------------
- Python 3.8+
- An OpenAI API key
- (Optional) SEC downloader credentials if required by `sec-edgar-downloader`
